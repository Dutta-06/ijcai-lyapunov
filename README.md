# When does gradient training choose the model order? Results of a factorized RBF network study

Status: **work stopped, not a finished paper.** This repository holds the result reports of a study of a Gaussian-kernel (RBF) network with a factorized readout (coefficient = mass x saturating amplitude), trained by plain gradient flow from a small initialization. The question: under which conditions does training itself decide how many units the network ends up using (units switch on one at a time, slide onto features of the data, and the rest stay dormant)?

The reports are generated by scripts from stored raw data (not included here). No paper text is included. The scripts and raw data are in a separate private repository. Every statement below was independently re-derived or recomputed by automated checks; **no human specialist has reviewed the proofs**, and the statuses below should be read with that in mind.

## Results, with their status

| Result | Status | Report |
|---|---|---|
| Exact one-unit solution for any readout depth p; dormant coefficients bounded by (eps b)^(p/2) mu^(-p/(p-2)); depth 2 selects only on a logarithmic scale of eps; depth 1 has no wall | proved for the scalar unit; the margin law for the trained network is observed, not proved | `results/synthetic/theory3d.md` |
| Entering orbit of the coupled entry layer (an entrant leaves the dormant state inside an invariant box, converges to the unique block critical point); separated-regime theorem for K = 2, n = 1, equal amplitudes, from about 4.7 kernel widths | entering orbit proved (uniqueness up to time shift: sketch); K = 2 conditions computer-evaluated, 0 violations in 45 000 independently generated targets | `results/synthetic/theory3y.md` |
| Entry layer and limit path for a general radial Gram (Gaussian 4.56-6.70, Laplace basis function, Matern, Wendland thresholds in kernel widths) | proved in the continuum; thresholds computer-assisted; not valid for sampled data with non-Gaussian kernels | `results/synthetic/theory3e.md` |
| The trained network follows the limit object (finite system S(eps)), verified in ball arithmetic with Krawczyk-enclosed limit data for every eps in (0, eps_top] on eight targets (n = 1, K <= 3); floating-point certificate on 771 grid pairs (471 informative, none contradicted) | computer-assisted; the hand proof of the implication is only partly independently re-derived; the enclosed critical points are not shown to be global minimisers | `results/synthetic/theory3n.md` |
| Small-noise theorem for the limit object (same entries in the same order, a stopping window, oracle fit up to an explicit remainder) | proved given a finite system; evaluated in double precision widened by 1e-9 (not an enclosure); the certified noise range is small; limit object only | `results/synthetic/theory3b.md` |
| Optimizers: sign descent gives every unit the same escape step; Adam without epsilon is scale-invariant for frozen drives; two layers from a pure small start escape only after a time of order eps^(-2) ln(1/eps) under gradient descent from exact zeros; hybrid conservation law | sign descent proved; Adam exact for frozen drives, observed in the coupled network; the discrete-time shared-second-moment claim is withdrawn | `results/synthetic/theory3f.md` |
| Optimizer test, 20 fresh targets x 2 noise levels x 3 seeds = 120 runs per arm (registered before scoring): gradient descent and a shared-second-moment Adam beat default Adam and sign descent by 0.49-0.60 in exact-edge share (merge radius 0.3); the gap shrinks with the merge radius and a merged L1-and-prune control is level or ahead from radius 0.4 | prediction held; supports the optimizer separation, **not** a better selector | `results/ml/optdepth.md` |
| Depth exponents p/2 | held for equal masses; unequal-mass test inconclusive; the registered monotone ordering of formed-set agreement with depth **failed** (four integrations at depth 5 failed) | `results/ml/optdepth.md` |
| One-layer Gaussian-unit KAN: the exact number of units appears on 72% of edges without a second stage | a merged L1-and-prune control matches it (post hoc); the fit is worse; two-layer start stays at its saddle; pre-registered verdict: kill | `results/ml/kan.md`, `results/ml/kan_merge.md` |

## What did not work

Attempts to turn the mechanism into a method that beats standard baselines (localization microscopy against Picasso and a learned localizer, crowded star fields against crowdsource and photutils, nucleus counting, heartbeat counting, additive models for tabular data, Gaussian primitives for images) did not clear their registered decision rules or were matched by simple controls, and are not reported here.

## Corrections made along the way

A displacement term of the certificate was mis-accounted in every verifier (found and repaired; two grid entries flipped; 473 informative pairs became 471); the "72% against 28%" KAN count was largely a missing merge step in the control; an "explanation" of a pooled margin exponent was an identity of the sample and was withdrawn; several statements about Adam were weakened to what is proved (frozen drives, sign descent) and what is observed.

## Unfinished

A separation sweep on the trained network and a teacher-student MLP test were started and stopped before finishing; they are not reported.

"Registered before scoring" means that plans and frozen configurations were committed with self-recorded timestamps; no external registry was used.
