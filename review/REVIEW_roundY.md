FINDINGS
1. [minor, wording] E2 (uniqueness up to time shift) is labelled PROVED, but NOTE §5 says the constants are non-explicit and the bookkeeping is "not carried out". I read the argument and found no error. It is a graph over alpha with an a^-2 strong contraction. The variation-of-constants kernel integrates correctly (the integral of e^{-lam(1/s-1/a)} s^-2 ds equals 1/lam). The centre estimate gives N(a)(1-C a^2)<=0. Structurally it is the uniqueness of the repelling centre-unstable branch of a saddle-node. Cheapest fix: label it "proof sketch / non-explicit". E4 can then say "every subsequential limit is an entering orbit; it is unique by E2".
2. [minor, wording] E3 says "constants in ball arithmetic". In theory3y_entry.bounds() the box constants (nu, d_hat, E_v, H_up, v_D_lo) are the `_mid` floats of box_t1. T2, T3, rho and pref are double precision, and only M_lower is a certified enclosure. The 113-122 figures are therefore not enclosures. The 24 tests pass. Fix: say "evaluated in double precision from ball-arithmetic box constants (midpoints)".
3. [minor, wording] E0 proves only the upper bound w_e <= (w_#^{-1/3} + c_M w_# |t|/3)^{-3}. supp_entry.tex line 12 says "v_e ~ |s|^-3", which is a two-sided claim. The matching lower bound (M_0 <= C w^{4/3}) is only numerically checked, and the constant is cited to T1 Cor 2.3. I rechecked the leading algebra: w ~ a_max^4 / (4 m v_s^2 G^3 (g|t|)^3). Fix: write "v_e = O(|s|^-3)".
4. [minor, number] The NOTE §9 says "(S0) holds from Delta = 4.66". My scan at h = 0.8333, r = h/2 + 0.02 gives S0 false at 4.69 and true from about 4.694, with nu = 0.0008 there. At 4.7, nu = 0.0058. Use 4.7. `box_for` tests the midpoint nu > 0, not the certified `ok` flag. `ok` also demands the Gershgorin margins beta_v, beta_d, which are T1's tracking conditions, not Prop A's (N); beta_d < 0 at 4.7. The margin is thin but positive, so this is a wording point. Say "midpoint nu > 0, ball-arithmetic enclosure of the other constants".
5. [minor, trap] S6' holds only for |A1| = |A2|. The formulas ignore amplitudes. Applied to benchmark targets with R = 2.4 (seeds 12, 24) the condition comes out TRUE while the recursion enters the kernels in the other order. That is outside the hypothesis, not a violation. The report's benchmark table correctly lists only the R = 1 targets. The theorem statement must carry "equal amplitudes".
6. [minor, gap] NOTE §3 Remark asserts P0 lies in the box B_k because "D*_S is inside int B". The layers use different grid-minimal radii r_{k-1} and r_k. This needs d_tilde(r_{k-1}) < r_k and v_hat >= v_lo(r_k), and it is not proved in general. All 44 layers satisfy it (the integrated flows pass the box_vlo_block and box_d checks). Fix: add the condition to the regime (or take one r per target, as S6' does with r = h/2 + 0.02).
7. [minor] The inequalities S1-S3 are evaluated in floating point. For the 4 covered benchmark targets the smallest margin is P_- - L1 = 1.45e-3 (seed 23). Label them "computer-evaluated".
8. [note] The face v = v_bar is only non-strictly inward (E_v = kappa(R + v_bar) gives exactly 0 drive for a unit of amplitude R; T1 line 232 handles this). Invariance still holds because the field is Lipschitz in (x,c) and Nagumo needs only non-strict inwardness. No change needed. Say "positively invariant", not "strictly inward".

ANSWERS TO THE ATTACK POINTS
(1) In x = alpha/a_max and c the ε=0 layer field is real-analytic, so it is Lipschitz and solutions are unique. P0 is an equilibrium, and {x_e = 0, c_e arbitrary, block at its critical point} is a line of equilibria. In w it is only C^1 (M_0 ~ w^{4/3}), still Lipschitz. The entering orbit is a genuine complete solution (v_e > 0 for all t) that takes infinite time to leave P0. Its existence uses no non-uniqueness. The compactness argument is correct: t_# tends to infinity (I measured t_# = 2.5e3 at v0 = 1e-8 and 5.2e4 at 1e-12, the v0^{-1/3} scaling). The alpha-limit step, the c_e tail bound and A = {P0} all check. For a fixed P0 the entering orbits form one time-shift class. Across different c_e^0 there is a family, but P0 fixes c_e^0.
(2) E0: I re-derived M = (G/m) q (q + 4 v_s sinh^2 x) and q = m w / (a_max sinh x cosh x); the proof is correct. Minimum of M/(c_M w^{4/3}) over 5 values of w_# and 41 values of eps (0 to 0.05) is 27.9, so the bound is uniform. Faces of B0: the sign needed is only non-strict (drive >= 0), so no positive mobility is needed on the block faces. On the entrant face v_e = 0 the drive is >= Gamma(r) - E_v > 0, and the centre face has w_e = 0 there, so those points are equilibria.
OWN INTEGRATION (Radau, rtol 1e-11) of the ε=0 layer from v0 = 1e-8 and 1e-12:
- Targets: layer 2 of (2,6,2.4,12), a target in the theory3n set (r = 0.2); a random K = 2 target (seed 999, R = 1.7, r = 0.3); and 6 stress layers at Delta 5.2/5.6, R 1/2.4, d0 = 0.4 toward the formed unit or away from it, opposite signs, r = 0.45.
- Results: the box holds throughout (max|d|/r equals d0/r, vmax/vbar <= 0.9999). v_e is monotone until v_lo and stays above it afterwards. The drive minus (Gamma(r) - E_v - v_e) has minimum slack >= 0.0066. All runs end at the target to <= 4e-16. Hitting times t_# are 1.06e3 to 5.4e4. The tail inequality holds. Only 8 layers (2 benchmark-type, 6 stress) were run, so that is the extent of the test.
- eps = 1e-6, 1e-8, 1e-10 from x_e = 0: v_e >= 0 and monotone, box holds, t_# ~ 10/sqrt(eps). The orbit distance to the ε=0 limit orbit at equal v_e levels is 9e-8 at 1e-6, then the floor of about 4e-10. The repository's own table shows 9e-5 over 44 layers with its own metric, a sampling-floor difference, not a contradiction. A rate roughly proportional to eps is observed, not proved.
