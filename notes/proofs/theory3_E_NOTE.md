# NOTE (theory round 3, direction E): the entry layer and the limit path for a general Gram

Author's working note. Numbers are from `results/synthetic/theory3e.md` (generated by `experiments/theory3e_run.py`; kernels `theory3e_kernels.py`, `theory3e_wendland.py`; simulator `theory3e_path.py`; tests `tests/test_theory3e.py`; mutants `tools/mutants/theory3e_kernels_own.py`).

## 0. Result in one paragraph

The fit F of the continuum network, and with it the whole entry-layer argument, depends on the kernel only through the Gram Gamma(|c-c'|) = <phi_c phi_c'>/Z (Gamma(0) = 1, the autocorrelation of the basis function). Prop. A and Thm K are therefore statements about a Gram, and the Gaussian specifics they used (Gamma and psi = -Gamma' decrease beyond sqrt 2, |Gamma''| beyond sqrt 6, psi(d) >= (d/2) Gamma(r), sup|Gamma'| = 0.43, n = 1) are replaced below by four kinds of numbers of Gamma: the *tail envelopes* m_0, m_1, m_2 (the coherence of the Gram), the *own constants* at a radius (Gamma(r), psi(r), inf psi(d)/d, sup psi, inf(-Gamma'')), and two global sups M_1, M_2. **Proposition G** (any radial C^2 Gram, any n) and **Theorem G** (the recursion of Thm K for it) are proved; the Gaussian case with the old cross-Hessian bound gives back 4.66/5.50/6.70/5.08/5.84 sigma exactly. **Corollary G1** is the clean form: the box conditions hold as soon as the *coherence index* (K-1) R^2 max(m_0,m_1,m_2)(Delta-2r) is below an explicit constant c_*(r) of the one-unit block (0.035 for the Gaussian at R = 1), whence Delta >= 2r + [a^{-1} ln(C(K-1)R^2/c_*)]^{1/q} for a decay modulus C exp(-a l^q) and Delta >= 2r + (C(K-1)R^2/c_*)^{1/s} for algebraic decay l^-s. The Laplace basis exp(-|x|) is *not* a smoothness failure (its Gram is Matern-(1+n/2), which is C^2: F only sees Gamma; the discontinuity of grad phi is invisible); the failure is a *cusped Gram* (Gamma'(0+) < 0, i.e. phi not in H^1), for which Prop. G'' gives the restricted statement (sliding mode: the centres lock exactly onto the features in finite time; no Hessian condition).

## 1. The class of Grams and notation

Basis function phi_0 in L^2(R^n) radial, kernels phi(x;c) = phi_0(|x-c|), Gamma(d) = (phi_0 * phi_0)(d e)/||phi_0||^2 (autocorrelation; positive definite). For the continuum network F = (1/2)<(y - sum w_i phi_i)^2> is, up to the factor Z, a function of the weights and centres through Gamma only.

**(G0) Regularity.** Gamma in C^2([0,inf)), Gamma'(0) = 0, lambda_0 := -Gamma''(0) > 0. (Equivalent: phi_0 in H^1(R^n); then x -> Gamma(|x|) is C^2 on R^n, -Hess Gamma(0) = lambda_0 I, lambda_0 = ||d_1 phi_0||^2/||phi_0||^2 = (1/n)||grad phi_0||^2/||phi_0||^2. Proof: Gamma''(0) = -<phi_0', phi_0'>-type identity by Plancherel, |phi_hat|^2 weights omega_1^2.) Length unit: **sigma-equivalent**, Gamma_eq(x) = Gamma(x/sqrt(2 lambda_0)) so that -Gamma_eq''(0) = 1/2 (the Gaussian of width sigma has Gamma = exp(-d^2/4)).
Write psi = -Gamma', rho = -Gamma'' ; for the Hessian of x -> Gamma(|x|) : -Hess = rho(|x|) xhat xhat^T + (psi(|x|)/|x|)(I - xhat xhat^T).

**Own constants** at radius x (needed on [0,x]): g(x) = min_{[0,x]} Gamma ; psi(x) ; lambda_psi(x) = inf_{(0,x]} psi(d)/d ; psihat(x) = sup_{[0,x]} psi ; rho_min(x) = inf_{[0,x]} rho. If lambda_psi(x) > 0 then Gamma is strictly decreasing on [0,x] and g(x) = Gamma(x).
**Tail envelopes** (the coherence of the Gram): m_0(l) = sup_{d>=l}|Gamma|, m_1(l) = sup_{d>=l}|Gamma'|, m_2(l) = sup_{d>=l} ||Hess Gamma(|x|)|| = sup_{d>=l} max(|Gamma''(d)|, |Gamma'(d)|/d) (n >= 2; for n = 1, sup|Gamma''|). The *coherence* of the Gram at separation Delta is mu(Delta) = m_0(Delta) = sup over pairs of kernels at distance >= Delta of the cross-Gram. M_1 = sup_{d>=0}|Gamma'|, M_2 = sup ||Hess|| (only for the dormant budget Omega).

## 2. Reduction (Lemma 1.1 unchanged)
Every flow met for a block and an entrant is v_i' = -M_i(v_i) dF/dv_i, c_i' = -mu_c dF/dc_i (c_i in R^n), M_i > 0 continuous, locally Lipschitz, mu_c > 0 a constant (matrix mobility: Cor. G2). The proof of Lemma 1.1 uses only the chain rule through the increasing map w = W^eps(eta) and c' = Gm w <r grad_c phi> = -Gm dF/dc; the latter requires grad_c phi in L^2, i.e. (G0). Nothing depends on the kernel.

## 3. Proposition G (the coupled entry layer for a general Gram)

Setting as in Prop. A: K features c*_k (amplitudes A_k, a_k = |A_k| in [1,R], R >= 1, a_min = 1) at mutual distances >= Delta; a set of m <= K units, unit i assigned to the distinct feature k(i), w_i = eps_i v_i, eps_i = sgn A_{k(i)}, c_i = c*_{k(i)} + d_i, d_i in R^n; the remaining features f_U unfitted; Omega >= 0 the total |coefficient| (units of a_min) of units outside the box (dormant units of the network; Omega = 0 for the limit object).
Box B = {|d_i| <= r, v_i in [v_lo, vbar]} for the units (entrant's lower face its starting value v_0 in (0, v_lo]), ell = Delta - 2r, and the coherence sums S_j = (K-1) m_j(ell) (j = 0,1,2) [or, for features at different distances, S_j = max_i sum_{k != i} m_j(Delta_ik - 2r) -- the proof uses only these sums]:
  kappa = S_0, vbar = (R(1+kappa) + Omega)/(1-kappa) (1+0+), E_v = kappa(R + vbar) + Omega, E_c = S_1 (R+vbar) + M_1 Omega, v_lo = g(r) - E_v, dtilde = E_c/lambda_psi(r).

**Proposition G.** Let kappa < 1 and
 (L) v_lo > 0 ; (C) psi(r) > E_c ; (N) lambda_psi(r) > 0, dtilde < r, g(dtilde) > E_v and lambda_own > H_c,
where, with s = R psihat(dtilde), t_rho = (g(dtilde)-E_v) rho_min(dtilde), t_perp = (g(dtilde)-E_v) lambda_psi(dtilde) (n >= 2 only):
 lambda_own = (1/2)(1 + t_rho - sqrt((1-t_rho)^2 + 4 s^2)) for n = 1 ; = min{that, t_perp} for n >= 2,
 H_c = ||D|| + ||B_sum||, D = [[0, E_cv],[E_cv, E_cc]], E_cv = S_1 (R+vbar) + M_1 Omega, E_cc = vbar (R+vbar) S_2 + vbar M_2 Omega, B_sum = [[S_0, vbar S_1],[vbar S_1, vbar^2 S_2]]
 (spectral norms of 2x2 symmetric nonnegative matrices). Let the initial point lie in B, the entrant with |d_e(0)| <= d_0 < r. Then for every positive mobility M_i and every mu_c > 0 (i)-(iv) of Prop. A hold: the trajectory stays in B; it converges to the unique critical point of F in B, nondegenerate, with |d_i| <= dtilde and |v_i - a_i Gamma(d_i)| <= E_v; while v_e < v_lo the entrant's coefficient strictly increases (levels crossed once, transversally); if Omega = 0 and all features are fitted the critical point is the target. (L), (C) alone give invariance of B and the monotone entry. Thresholds: Delta_entry(K,R,d_0;Gamma) = least Delta for which some r > d_0 satisfies (L),(C),(N).
Status: **PROVED** (below), evaluation of (L),(C),(N) in ball arithmetic is **COMPUTER-ASSISTED**.

*Proof.* Notation as in THEORY_NOTE sec. 1: e_i = a_i phi*_{k(i)} - v_i phi_i, rest_i = sum_{j != i} eps_j e_j + f_U - (dormant terms), F = (1/2)<(sum_i eps_i e_i + f_U)^2> is a function of Gamma only because <phi_c phi_c'> = Z Gamma(|c-c'|) (Z = 1).
*Step 0 (field).* <e_i, phi_i> = a_i Gamma(|d_i|) - v_i, so -dF/dv_i = a_i Gamma(|d_i|) - v_i + eps_i P_i with P_i = <rest_i, phi_i>. The own part S_i = (1/2)(a_i^2 - 2 v_i a_i Gamma(|d_i|) + v_i^2) has grad_d S_i = v_i a_i psi(|d_i|) dhat_i, so grad_{c_i} F = v_i [ a_i psi(|d_i|) dhat_i - eps_i C_i ], C_i = <rest_i, grad_c phi_i> (vector).
*Step 1 (couplings).* In B the distance from c_i to c_j, c*_j (j in the box), c*_u (u unfitted) is >= ell = Delta - 2r (>= Delta - r for the last two), and |<phi_i, e_j>| <= (a_j + v_j) m_0(ell), |<grad phi_i, e_j>| <= (a_j + v_j) m_1(ell) (m_j are envelopes, so no monotonicity of Gamma is needed). The dormant units add at most Omega M_0 <= Omega (|Gamma| <= 1) to P and Omega M_1 to |C|. Hence |P_i| <= E_v and |C_i| <= E_c on B (sum over the K-1 other features; v_j <= vbar, a_j <= R).
*Step 2 (faces; Nagumo).* On v_i = vbar: -dF/dv_i <= a_i - vbar + E_v < 0 because vbar > R + E_v by construction. On v_i = v_lo (v_0 for the entrant): -dF/dv_i >= a_i Gamma(|d_i|) - v_lo - E_v >= g(r) - v_lo - E_v >= 0 (a_i >= 1; |d_i| <= r; strict for v_0 < v_lo and for v_lo slightly below g(r) - E_v). On |d_i| = r: d/dt (1/2)|d_i|^2 = -mu_c v_i [a_i psi(r) r - eps_i d_i . C_i] <= -mu_c v_i r [a_i psi(r) - E_c] < 0 by (C) (a_i >= 1). With strict faces and positive mobilities (v_i >= min(v_0, v_lo) > 0) B is positively invariant.
*Step 3 (convergence).* F is non-increasing along the flow and constant in B only at critical points; LaSalle: omega-limit set nonempty, connected, consisting of critical points in B.
*Step 4 (location, nondegeneracy, uniqueness).* At a critical point of B: a_i psi(|d_i|) = |C_i| <= E_c and, as psi(d) >= lambda_psi(r) d on (0,r] (definition of lambda_psi, monotone in the radius), |d_i| <= E_c/(a_i lambda_psi(r)) <= dtilde < r; v_i = a_i Gamma(d_i) - eps_i P_i in [g(dtilde) - E_v, R + E_v]. Hessian in (v_i, d_i): block-diag of the own blocks [[1, a_i psi(|d|) dhat^T],[., v_i a_i (rho dhat dhat^T + (psi/|d|)(I - dhat dhat^T))]] (n = 1: [[1,s],[s,t]]) plus a cross part H_cross. On the convex set D* = {|d_i| <= dtilde, v_i in [g(dtilde) - E_v, R + E_v]} the own block's least eigenvalue is >= lambda_own: on the plane spanned by (v, dhat) it is [[1, s_i],[s_i, v_i a_i rho(|d|)]] with s_i = a_i psi(|d|) <= s and v_i a_i rho >= (g(dtilde) - E_v) rho_min(dtilde) = t_rho whenever that is positive (a_i >= 1; if it is not, lambda_own <= t_rho <= 0 and (N) fails, nothing to prove), whose least eigenvalue increases with t and decreases with |s|; on the n-1 tangential directions it is v_i a_i psi(|d|)/|d| >= t_perp (n >= 2). H_cross has the block structure: for i != j, H_ij (differentiate the cross terms of F: a_i a_j Gamma(c*_i - c*_j) - a_i v_j Gamma(c*_i - c_j) - v_i a_j Gamma(c_i - c*_j) + v_i v_j Gamma(c_i - c_j)) has entries bounded by the matrix B = [[m_0, vbar m_1],[vbar m_1, vbar^2 m_2]](ell) (the v_i v_j-term gives d_{v_i}d_{v_j} = Gamma, d_{v_i} d_{c_j} = v_j grad Gamma, d_{c_i} d_{c_j} = -v_i v_j Hess Gamma, the other terms depend on one of the two units only); the diagonal block H_ii (the coupling of unit i to the other units, to f_U and to the dormant units) is [[0, beta^T],[beta, Delta_ii]] with |beta| <= S_1 (R + vbar) + M_1 Omega, ||Delta_ii|| <= vbar (R+vbar) S_2 + vbar M_2 Omega (d_{v_i}d_{c_i}: -a_j grad Gamma(c_i - c*_j) + v_j grad Gamma(c_i - c_j); d_{c_i}d_{c_i}: v_i[-a_j Hess + v_j Hess]; unfitted features: a_j replaced by A_u, same bound; M_1, M_2 for the dormant terms). A block [[alpha, beta^T],[gamma, Delta]] has operator norm <= the norm of [[|alpha|, |beta|],[|gamma|, ||Delta||]] ; for a symmetric block matrix ||H_offdiag|| <= max_i sum_{j != i} ||H_ij|| (Schur test), ||blockdiag|| = max_i ||H_ii||. Hence ||H_cross|| <= ||D|| + ||B_sum|| = H_c. By (N) the Hessian of F is positive definite on D*, which contains every critical point of B; F is strictly convex on D*, so there is at most one critical point in B, nondegenerate; the omega-limit set is that point: (ii).
*Step 5 (monotone entry).* dv_e/dt = M_e(v_e)[a_e Gamma(|d_e|) + eps P_e - v_e] >= M_e [g(r) - E_v - v_e] > 0 for v_e < v_lo: (iii). *Step 6.* If all features are fitted and Omega = 0, rest_i contains no unfitted term and F = 0 is attained at the target, which lies in D*; by uniqueness it is the critical point: (iv). Both mobility (any) and mu_c (any) enter only through positivity. QED

**The entering orbit** (Prop. A's remark) is unchanged: the entrant leaves v = 0 only asymptotically, the coupling of the block to it is O(v_e) and the entrant's centre moves by an integrable amount, so the orbit lies in B from some time on provided r > d_0 strictly.

**What changed relative to Prop. A, and why it is not an approximation.** (1) psi, Gamma, |Gamma''| monotonicity beyond sqrt 2 / sqrt 6 -> envelopes m_j (Step 1). (2) psi(d) >= (d/2) Gamma(r) -> lambda_psi(r). (3) The block entries (1/2 - d^2/4) Gamma and Gamma/2 -> rho_min, lambda_psi, psihat. (4) 0.43, 1/2 -> M_1, M_2. (5) n > 1: tangential stiffness, block norms. (6) H_c: the Gaussian note bounded ||H_cross||_2 by the maximum absolute row sum of the entries (a valid bound, but looser); here it is bounded by block spectral norms (valid in every n). Regression: with the row-sum bound in place of (6) and n = 1 the code returns the paper's table exactly (4.66, 5.50, 6.70, 5.08, 5.84), with the block-norm bound 4.56, 5.44, 6.70, 5.00, 5.80: the refinement is the only change to the Gaussian numbers.

## 4. Theorem G (the recursion for a general Gram)
Definition of the limit object and of the recursion (piecewise-linear duals with the rates p_j = <r_k phi_j> = sum_m A_m Gamma(|c_j - c*_m|) - sum_{i<=k} w_i Gamma(|c_j - c_i|), entrant argmin (1 - sgn(p_j)u_j)/|p_j| assigned to the nearest unfitted feature at offset d_0^{k+1}, block = the critical point of Prop. G) is verbatim that of Thm K. **Theorem G.** Equal walls, continuum Gram of a basis function satisfying (G0). Suppose for every k < K: (a) the minimiser is unique and its dual has the sign of the feature's amplitude; (b) |u_j| < 1 at the entry time for every other inactive j; (c) (L), (C), (N) of Prop. G hold with a radius r > d_0^{k+1} at the separation Delta and ratio R (Omega = 0). Then the limit object has exactly K entries, the kernels j_1..j_K, no exit; its final block is the target with zero residual; (H1) holds with margin min_k(1 - max_j |u_j|), (H3) by Prop. G, (H2) with a rate depending on the mobility, and (H4) at levels below v_lo a_min.
Status: **PROVED** given Prop. G; (a), (b) are finite computations on the target, (c) is COMPUTER-ASSISTED (ball arithmetic). *Proof* = that of Thm K (induction; between entries the block is stationary, the inactive duals are piecewise linear and |u_j| convex on each piece, so only the entrant reaches the wall, transversally; Prop. G relaxes the layer in zero slow time; no coefficient vanishes: no exit). QED
Neither the kernel nor n appears in the induction.

## 5. Corollary G1 (the clean condition, through the coherence)
Let c(Delta; r) = (K-1) R^2 max(m_0, m_1, m_2)(Delta - 2r) (the **coherence index**; with the Babel-type sums S_j: R^2 max_j S_j). Let r > d_0 and c_1 <= 1/4 be such that, with e = 2.7 c_1 and d_1 = e/lambda_psi(r),
 (i) e < g(r), (ii) e < psi(r), (iii) d_1 < r, (iv) Lambda(d_1) > 12 c_1,
Lambda(d_1) = the least eigenvalue floor of the one-unit block on |d| <= d_1, v >= g(d_1) - e (the 2x2 formula with s = R psihat(d_1), t_rho = (g(d_1)-e) rho_min(d_1), and for n >= 2 min with (g(d_1) - e) lambda_psi(d_1)). **If c(Delta; r) <= c_1 then (L), (C), (N) hold.**
*Proof.* kappa = S_0 <= c(Delta;r)/R^2 <= 1/4, so vbar <= (R(1+kappa)/(1-kappa))(1+0+) <= 1.7 R and R + vbar <= 2.7 R. Then E_v = kappa(R+vbar) <= 2.7 R kappa <= 2.7 c_1, E_c <= 2.7 R S_1 <= 2.7 c_1 (Omega = 0; R S_1 <= c/R), so (i),(ii) give (L),(C); dtilde = E_c/lambda_psi(r) <= d_1 < r, and every infimum/supremum over [0,dtilde] is bounded by that over [0,d_1] (monotone in the radius), so lambda_own >= Lambda(d_1). Finally, with E_cv = S_1(R+vbar) <= 2.7 R S_1 <= 2.7 c_1 and E_cc = vbar(R+vbar) S_2 <= 1.7*2.7 R^2 S_2 <= 4.59 c_1 (using R S_1 <= c/R <= c_1 and R^2 S_2 <= c_1): ||D|| <= E_cv + E_cc <= 7.29 c_1; and for B_sum = [[S_0, vbar S_1],[vbar S_1, vbar^2 S_2]]: S_0 <= c_1, vbar S_1 <= 1.7 c_1, vbar^2 S_2 <= 2.89 c_1, so ||B_sum|| <= max(S_0 + vbar S_1, vbar S_1 + vbar^2 S_2) <= 4.59 c_1. Hence H_c <= 11.88 c_1 <= 12 c_1 < Lambda(d_1) <= lambda_own. QED
Numbers: c_*(r) = sup of admissible c_1 is 0.0349 (Gaussian, R = 1, r = 0.45), about 0.031 (R = 2.4), 0.017 (R = 10) (floating point with directed kernel bounds; the corollary is an implication, checked against the sharp box in the tests, at the extremal separation and on random inputs; the field and Hessian bounds of its proof are also checked on F itself by finite differences at random points of the box, n = 1, 2, K = 2, 3). Clean thresholds (K = 2, R = 1): Gaussian 5.24 (sharp 4.56), Laplace basis n = 1 8.56 (6.72), Matern-3/2 basis 5.68 (5.04), Matern-5/2 basis 5.52 (4.84); the clean form loses 0.6-1.8 sigma, more for heavy tails and large R (R = 10: Gaussian 7.50 vs 6.70; Laplace 17.0 vs 12.7). **Decay form.** If m(l) := max(m_0,m_1,m_2)(l) <= C exp(-a l^q) for l >= l_0 then the conditions hold for Delta >= 2r + [a^{-1} ln(C (K-1) R^2/c_*(r))]^{1/q}; if m(l) <= C l^{-s}: Delta >= 2r + (C (K-1) R^2/c_*(r))^{1/s}. For K features in R^n the factor (K-1) is replaced by the Babel sum max_i sum_{k != i} m(Delta_ik - 2r)/m(...), and for a lattice of features of spacing Delta this is the coordination number of the lattice (2n for the cubic lattice, 6 in the plane (triangular), 12 (fcc)) times m(Delta - 2r) plus the further shells: the dimension enters through the Gram Gamma_n (its decay), the coordination number and the tangential stiffness, nowhere else.

## 6. The cusp: Proposition G'' (the correct restricted statement for a non-smooth Gram)
The smoothness assumption (G0) can fail in exactly one way that matters: Gamma'(0+) = -kappa_0 < 0 (a *cusp*; e.g. the Gram exp(-d), whose basis function has the Fourier transform (1+w^2)^{-1/2} and is not in H^1). Then the own term v a Gamma(|d|) = v a (1 - kappa_0 |d| + ...) is a convex kink in d: F is not differentiable on {d_i = 0}, grad_c phi is not in L^2, and the network's centre force <r grad_c phi> does not exist for the continuum object. (The Laplace basis exp(-|x|) is *not* this case: its Gram is C^2.) Restricted statement: define the limit/inner flow as a Filippov solution of the differential inclusion z' in -diag(M_i, mu_c) dF(z) (Clarke subdifferential: d(|d_i|) at 0 is the closed unit ball). With Gamma(d) = e^{-d} (kappa_0 = psi_min(r) e^{r} = 1):
 (L) g(r) > E_v ; (C') psi_min(r) = inf_{(0,r]} psi > E_c (here e^{-r}) ; kappa < 1 .
**Proposition G''.** Under these, every Filippov solution started in B stays in B, every unit's offset reaches 0 in finite time (<= r/(mu_c v_min (psi_min - E_c))) and stays 0 (sliding mode: the inclusion contains 0 because |C_i| <= E_c < a_i kappa_0), the coefficients then follow the gradient flow of the strictly convex quadratic F|_{d=0} (Hessian = the Gram of the features >= 1 - kappa) and converge to its unique minimiser; the only critical point in B has all d_i = 0 (if d_i != 0 the balance a_i psi(|d_i|) = |C_i| is impossible); with all K features fitted it is the target; the entrant's coefficient increases while below v_lo (the v-component of the field is single-valued and continuous). No Hessian condition (N) and no Lipschitz theory of the ODE is used; uniqueness of the solution is not claimed. Status: **PROVED** (inclusion-valued); it concerns the inner flow of the idealised limit object, not a trained network (OUTLINE for anything about the network with such a kernel). The smoothed cusp Gamma_delta = exp(-(sqrt(d^2+delta^2) - delta)) integrated confirms locking to O(delta) (report D).
*Proof.* Faces: the v-faces and the |d_i| = r faces are away from {d_j = 0} for the component they test (the set-valuedness is in the d_j components only), so Nagumo's condition for inclusions holds as in Prop. G (psi(r) >= psi_min > E_c). Locking: while d_i != 0, d|d_i|/dt = -mu_c v_i [a_i psi(|d_i|) - eps_i dhat_i . C_i] <= -mu_c v_min (psi_min - E_c) < 0. Convergence of the v's on d = 0: gradient flow with positive mobility on a strictly convex quadratic. QED

## 7. Anisotropic Gaussian with a common covariance (Corollary G2)
phi(x;c) = exp(-(1/2)(x-c)^T S^{-1} (x-c)): Gram exp(-(1/4)(c-c')^T S^{-1}(c-c')). In y = S^{-1/2} c it is the isotropic Gaussian Gram and the centre flow c' = -mu_c grad_c F becomes y' = -mu_c S^{-1} grad_y F: a matrix mobility with condition number cond(S). Prop. G holds in y (box |d'| <= r, separation = the Mahalanobis separation, worst case Delta_E/sqrt(lambda_max(S))) with (C) replaced by psi(r) > cond(S) E_c: only Step 2's centre face uses the mobility (d/dt(1/2)|d'|^2 = -v d'^T mu S^{-1}[a psi dhat' - C'] <= -v |d'| mu [lambda_min(S^{-1}) a psi(r) - ||S^{-1}|| E_c]). **PROVED**; the numbers (K = 2): Delta_entry = 4.56, 4.68, 5.08, 5.52, 6.48 for cond = 1, 2, 4, 10, 100 (R = 1). Different widths per unit (sigma_i != the features'): not covered -- the Gram of unit i with feature k is then a different function and the single-unit minimiser no longer has zero residual; the conditions would need the pairwise Gram.

## 8. Instantiations (report sections A-C; thresholds in sigma-equivalents, d_0 = 0.4167, K = 2, R = 1 unless stated)
Gram = autocorrelation of the basis function; the Matern-nu basis in R^n has the Fourier transform (1+w^2)^{-(nu+n/2)}, so its Gram is Matern-(2 nu + n/2) (checked numerically against the autocorrelation for the Laplace basis in n = 1,2,3 and the Matern-3/2 basis in n = 1,3).
* Gaussian: Gamma = exp(-d^2/4) for every n, hence no n-dependence at all: 4.56 / 5.44 / 6.70 / 5.00 / 5.80 for (K,R) = (2,1), (2,2.4), (2,10), (3,1), (3,2.4) with the block-norm cross-Hessian bound; **4.66 / 5.50 / 6.70 / 5.08 / 5.84 with the paper's row-sum bound (regression, exact)**. Only the starting offset depends on n: the worst offset of a cubic lattice of spacing 0.833 sigma is sqrt(n) 0.4167 (0.589, 0.722), giving 4.90 and 5.18 for n = 2, 3.
* Laplace basis exp(-|x|): the *basis* is not smooth, the *Gram* is Matern-(1+n/2): 3/2, 2, 5/2 for n = 1, 2, 3, C^2 but not C^3 at 0 in n = 1. Only (G0) is used, so the theory applies verbatim: 6.72 / 5.70 / 5.34 sigma (n = 1,2,3; K = 2, R = 1), 8.60 / 7.26 / 6.76 at R = 2.4, 12.7 / 10.5 / 9.5 at R = 10. The tail e^{-d} (algebraic prefactor) makes the R-dependence much stronger than for the Gaussian. The thresholds fall with n only because the Laplace basis' Gram is smoother in higher n (nu_G = 1 + n/2).
* Matern-3/2 basis (Gram nu_G = 7/2, 4, 9/2): 5.04 / 4.96 / 4.92; Matern-5/2 basis (nu_G = 11/2, 6, 13/2): 4.84 / 4.80 / 4.80: monotone decreasing towards the Gaussian's 4.56 as the smoothness grows (the Gaussian is the limit nu -> infinity).
* Rational-quadratic Gram (algebraic decay l^{-2 beta}; a scale mixture of Gaussians, PD in every n): 5.20 / 4.98 / 4.80 for beta = 2, 3, 5; the clean algebraic form gives 7.45 / 6.95 / 7.12 (K = 2, R = 1, r = 0.45).
* Wendland psi_{1,1} (n = 1), psi_{3,1} (n = 3) (compact Gram: support 2 raw = 6.20 / 7.35 sigma-equivalents; n = 2 not computed): **trivial bound** (no numerics): beyond the support every tail vanishes, S_j = 0, E_v = E_c = H_c = 0 and the conditions reduce to Gamma(r) > 0, psi(r) > 0, lambda_0 > 0, i.e. exact decoupling for Delta >= supp + 2 d_0 (7.03 / 8.18). **Ball-arithmetic threshold** (the polynomial pieces re-expanded about the support edge, exactly, so that the enclosure of the tiny tails near the edge is not destroyed by cancellation between monomial coefficients): 4.50 / 5.28 / 6.10 / 4.88 / 5.54 (n = 1) and 4.54 / 5.34 / 6.32 / 4.94 / 5.64 (n = 3) for the five (K,R): close to the Gaussian's, because the Wendland Gram vanishes to high order at the support edge. (A first run with monomial-basis balls gave 7.04 / 8.20 -- an artefact of a vacuous enclosure of the tail, caught by the tests' tightness check; it was sound but not sharp.)
* Cusped Gram exp(-d) (Prop. G''): 1.58 / 2.26 / 3.58 / 2.28 / 2.96 correlation lengths (3.8 / 5.4 / 8.6 / 5.5 / 7.1 half-height sigma): smaller than the smooth Matern-3/2's because (N) is absent; the price is the non-smoothness of F at the features.
* Anisotropic Gaussian, common covariance (Cor. G2): K = 2, R = 1: 4.56, 4.68, 5.08, 5.52, 6.48 for cond(S) = 1, 2, 4, 10, 100 (whitened units).

Status: COMPUTER-ASSISTED instances (double precision except the box constants, a single target and a decade grid per Gram, no monotonicity in eps), and the *claim that the proof only uses the replaced quantities* is a reading of the proof, not re-derived line by line: OUTLINE for T1 beyond the Gaussian.
