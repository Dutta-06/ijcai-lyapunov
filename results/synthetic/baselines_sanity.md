# Are the order-selection baselines a strawman? Forward selection, penalised training and random start + prune, checked on cases with a known answer

Generated by `experiments/exp_baselines_sanity.py` from `baselines_sanity_raw.npz`; every number below is printed by the script; the analyses were declared in the script's docstring before the runs. The comparison under test is `results/chaos/noise_order.md` (432 trials, `experiments/exp_noise_order.py`); the frozen code is imported, not edited. Intervals are 95 % Wilson intervals over trials unless a bootstrap over targets is named. Counting conventions: V0 = the comparison's (units counted one by one); V1 = units merged into clusters (single linkage, link 0.12 = one width; clusters below 0.1 of the largest mass dropped) and clusters counted; V2 = V1, then the clusters' masses and centres slid jointly on least squares and units that coincide merged again. "Exact" is K-hat = K; "exact and placed" also needs all K true features matched within half a width.

## What each baseline does in the comparison

- **Forward selection (`step`).** Least squares on the 21 grid kernels (centres stay on the grid), greedy, at most 10 units, the block by BIC with one parameter per unit; K-hat = the number of grid kernels chosen. It cannot place a centre between grid points, so an off-grid feature is fitted by several neighbouring kernels.
- **Penalised network (`pen`).** 21 units, centres trainable (start on the grid), coefficients start at 0.1 N(0,1); proximal gradient descent, 2500 steps, at 7 penalties 3e-04 ... 3e-01, the penalty by BIC with two parameters per nonzero coefficient; K-hat = the number of nonzero coefficients. The l1 norm of the coefficients does not change when a unit is split into two at the same centre, so units that sit at one centre are counted one by one.
- **Random start + prune (`prune`).** The same network without a penalty from a random start of scale 0.3, 5000 steps, units with |w| below 0.1 max|w| removed; K-hat = the survivors. Nothing in the training sparsifies the coefficients.
