# Normalised optimizers erase the ordering; the two-layer small start does not leave its saddle

Generated by `experiments/theory3f_escape.py --from-raw`; proofs in the round note (outside the repository); tests `tests/test_theory3f_escape.py`.

## Statements and their status

* **F1a (sign descent; PROVED, checked below).** Units `w_i = W(p_i)` with a common start and common step sizes, trained by `p <- p + lr*sign(-dL/dp)`; let `T` be the first step at which `|W(p(t))| >= theta` along the path of a unit whose drive `g_i(t) = <r phi_i>` keeps its sign. Then every unit whose drive keeps its sign up to `T` has the SAME parameter path, hence crosses at the same step, whatever the ratio of the drives; for D3 (`w = u^3 - v^3`, start `(s, s)`) `T = min{t: 2(3 s^2 lr t + (lr t)^3) >= theta}`, which tends to `ceil((theta/2)^(1/3)/lr)` as `s -> 0`: the small start does not set the escape time. Hypotheses: `|g_i(0)| > theta*sum_j |G_ij|` (the drive cannot turn before `theta`); a generic start (if `v` hits exactly 0, `dw/dv = 0` and the sign update stops that coordinate: the runs use starts that are not multiples of the step). With starts `s_i` the steps differ by at most `eps |b_i - b_j|/(a_0 lr) + 1` (`s_i^2 = eps b_i`, `a_0 = (theta/2)^(1/3)`).
* **F1b (Adam, `eps_adam = 0`; PROVED).** The Adam update is invariant under a positive rescaling of the gradient history, so units with PROPORTIONAL gradient histories (a frozen drive) have identical trajectories (exact). For positive nondecreasing gradient sequences `1 - beta1 <= R_t <= C(beta1, beta2)` (`C = 7.27` for `(0.9, 0.999)`), so the escape steps of any two such units are within the factor `C/(1 - beta1)`, independent of the drives. With `eps_adam > 0` the same holds while `eps_adam <= kappa*sqrt(vhat_t)` (up to `1/(1 + kappa)`); the dormant gradient is `3 g s^2` for D3.
* **F1c (the pair, duplicates; sign descent).** Atom 1 is the target, atom 2 has overlap `rho`. PROVED: both units follow the same path (`w_1 = w_2`) until the drive of atom 2 turns, so `peak |w_2| >= rho/(1 + rho)` (up to one step's increment); gradient descent keeps atom 2 at the dormant scale. NUMERICAL: afterwards atom 2 slides along `w_2 = rho(1 - w_1)` and the end state is the sparse fit up to the chatter of size `lr` (the path, not the limit point, is wrong). PROVED for duplicate atoms (equal drives at every step): `u_1 - u_2 = s_1 - s_2` for all time, `w_2/w_1 = (3 s_2^2 + a^2)/(3 s_1^2 + a^2)` with a common `a`, so the amplitude is shared (ratio `1 - O(s^2)`); gradient descent: the larger start takes all.
* **F1d (what keeps the mechanism).** PROVED: (0) any update of the form `p_i += lr*Phi(history of the gradient of unit i)` with `Phi` invariant under positive rescaling of its argument (sign descent, Adam with `eps_adam = 0`, RMSprop, per-coordinate normalisation in ANY coordinates, in particular in the mirror coordinates `eta` where the flow is `eta_i' = g_i`; per-group step sizes only rescale `lr`) gives identical trajectories to units with proportional gradient histories: the ordering by the drive is lost; (i) GD: escape time `(1/s - 1/u_c)/(3 g)`, ordered by `g`; (ii) Adam with `eps_adam >= K max_t sqrt(vhat_t)` is momentum SGD with the rate `lr/eps_adam` up to the factor `1 + 1/K` (inequality on the update); (iii) normalised gradient descent with the GLOBAL norm is gradient flow run on the clock `d tau = dt/||grad||` (same orbits); (iv) one SHARED scalar second moment (`adam_g`, `beta1 = 0`) is gradient descent with a positive variable step: same orbits (a scale shared by all units keeps the relative speeds `g_i dW/dp`). NUMERICAL (D, D2, F, H, K): a large `eps_adam` restores the sliding path on the pair (crossover `eps* ~ c rho s/(1 - rho)`), on the design (D3: the number of formed units falls 21, 10, 8, 5, 3 as `eps_adam` rises from 1e-8 to 3e-3, then exactly the path's set; the paper's unit P0 at the long horizon of its wall) and on the additive KAN (exact-edge share 0.60 at `eps_adam = 1`, 0.43 at 0.01, against 0.67 for gradient descent and 0.27 for Adam); the shared second moment restores it on the pair (for rho = 0.8 and s = 0.013 the peak of atom 2 is 1.0e-3, at the formed threshold, against 2.5e-4 for gradient descent), on the design (D3 and P0) and on the additive KAN (0.70).
* **F2a (the product of D small factors; PROVED, quadrature).** Balanced start `z = s`, `w = z^D`, drive `g`: time to `z_theta` is the quadrature in the module docstring: `ln(1/s)/g + O(1)` for `D = 2` (the diagonal two-layer network, `w` logistic: `w(t) = g/(1 + (g/w_0 - 1) exp(-2 g t))`) and `s^-(D-2)/((D-2) g) + O(1)` for `D >= 3`. With `s^2 = eps b` (the repo): `eps^(-(D-2)/2)`; `D = 3` is the repo's unit (`eps^(-1/2)`), `D = 4` (a cubic unit times a linear second layer) `eps^(-1)`, `D = 6` (two cubic layers) `eps^(-2)`.
* **F2b (the paper's start in two layers; PROVED).** If the coefficients of both layers are zero (`w = 0`: alpha = 0 for the paper's unit, `(s, s)` for D3) and the target is centred, the vector field vanishes (each layer's gradient is proportional to the other layer's coefficient or to the correlation of the target with the other layer's output): the whole set is stationary, for every optimizer with `eps_adam > 0`. A perturbation `a_0` of one layer gives `T = (ln(s/a_0) + O(1))/(lr c* s^4)` for the unsaturated pair (exact quadrature for the symmetric start; the pair conserves `alpha_2^2 - alpha_1^2`, so the start `(0, a_0)` is the symmetric start `a_0/2` up to `O(a_0^2)`: equal to 9 digits at `a_0 = 1e-6`).
* **F2c (the hybrid; PROVED).** First layer cubic units `u_kl^3` from `s`, second layer `b_k(0) = b_0 > 0`, rates 1: `b_k^2 - (1/3) sum_l u_kl^2 = b_0^2 - (1/3) n s^2` for all times, and the escape of the leading unit satisfies `int_s^U du/(3(1+delta) g u^2 b_max(u)) <= T <= (1/s - 1/U)/(3(1-delta) g b_0)`, `delta` = the relative variation of its drive, `b_max(u)^2 = b_0^2 + (n_+/3)(u^2 - s^2)`: the one-layer escape with the effective drive `b_0 g` (exponent `eps^(-1/2)` kept) when `b_0^2 >> U^2 n_+/3`.
