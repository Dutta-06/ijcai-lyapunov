# Theory round 3, direction E: the entry layer and the limit path for a general Gram

Generated by `experiments/theory3e_run.py` (kernels: `theory3e_kernels.py`, `theory3e_wendland.py`; simulator: `theory3e_path.py`); the statements and proofs are in the round's NOTE.md (Proposition G, Corollary G1, Proposition G'', Theorem G). Lengths are in sigma-equivalents, defined once here: the curvature-matched unit in which -Gamma''(0) = 1/2, so that the Gaussian of width sigma has Gamma(d) = exp(-d^2/4) (for a non-Gaussian basis function it is NOT the width of anything); the starting offset is d_0 = 0.4167, half the dictionary spacing 0.833 in these units (the benchmark's h/(2 sigma)); every threshold is conditional on that spacing, unless stated. Ball arithmetic: python-flint; every kernel number is a directed float bound turned into an exact ball (tails: upper; own minima: lower), so `ok` means the strict inequalities are certainly true (beyond L = 40 sigma the three envelopes |Gamma|, |Gamma'|, |Gamma''| are assumed non-increasing; hand-proved for the half-integer Matern Grams only).

**Status and scope** (referee round T3E, `review/REVIEW_roundT3E.md`).

* Scope: every statement for a non-Gaussian Gram is for the CONTINUUM inner product (L2(R^n)) with the data spacing small against the kernel's correlation length. On sampled data the Gram of the Laplace basis has a cusp in c at every data point, so Proposition G does not apply to a sampled Laplace network (it behaves like a cusped Gram near data points). No non-Gaussian network exists in the repository; the network evidence for these Grams is the continuum simulator `theory3e_path.simulate_network`.
* Wording: "Laplace BASIS function exp(-|x|)", not "Laplace kernel". If "kernel" were read as the Gram exp(-d), the case would be the cusp Proposition G'', not Proposition G. The rational-quadratic and Wendland rows are Gram classes (the rational-quadratic Gram has no natural basis function; Wendland is the basis function, its Gram is the support-2 autocorrelation).
* Tail envelopes: |Gamma|, |Gamma'|, |Gamma''| beyond L = 40 sigma-equivalents are ASSUMED non-increasing (checked numerically; hand-proved for the half-integer Matern Grams only). The tabulated rows are computer-assisted sufficient thresholds conditional on this assumption.
* T1 beyond the Gaussian: only the computed instances of Part H (one target each for four n = 1 Grams), not Theorem T1 for general Grams; no slowly decaying (algebraic) Gram was run, and for the rational-quadratic lattice sums 2 beta > n is needed.
* The network-following evidence of Part G does NOT test certification: uncertified targets follow the recursion as well as certified ones (counts in Part G); the threshold Delta_entry is a sufficient, conservative bound, not a transition separation. It is not used as validation.

## G. The limit path against the network flow

One target per row (`theory3e_path.make_target`, fixed seeds): K features on a line (random direction in R^n) at separation Delta, the dictionary a cubic lattice of spacing 0.833 sigma. "threshold" is Delta_entry for the target's own K, R and its largest entrant offset; "certified" = Delta >= threshold, every entrant has its feature's sign (a) and all inactive duals stay below the wall (b); "margin" = 1 - max |u_j|; "final err" = |block - target| of the recursion.
