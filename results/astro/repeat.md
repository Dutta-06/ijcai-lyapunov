# Held-out test on repeat imaging of M2: the frozen configuration and the kernel rule at other seeing

Generated by `experiments/exp_astro_repeat.py` from `repeat_raw.npz` (and the frozen `m2_raw.npz`, read only); every number below is printed by the script. The analysis was declared in `repeat_plan.md` before any run; the freeze record `freeze_repeat.json` hashes the plan, the code and the inputs, and the run refused to start unless it matched. **Nothing was re-tuned on these patches**: the configuration (sigma_b 3, r_ex 1.2, kappa 2), the a priori default (5, 1.2, 5), the BIC stop, the kernel rule (`psf_general.fit_adequate`, rms goal 0.002 of the peak) and the baselines' choices come from the M2 development patches and the M53/M92 episode. The windows are the M2 test windows (same sky, same HUGS stars): images, PSFs and noise are new, the truth and its defects are shared. Six patches from three frames: the unit of replication for the seeing is the frame. Intervals: 95 % percentile intervals of a bootstrap over the 20 x 20 px blocks (2000 resamples, seed 0, stratified within each patch, the same resamples for every row of a table, so differences are paired); they are conditional on the patches. Magnitudes from counts use M2's fixed zero point for every frame (0.03 to 0.08 mag offset, `repeat_spec.md`).
