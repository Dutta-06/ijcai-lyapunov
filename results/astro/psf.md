# The kernel of the sliding path against the PSF stamp: a post hoc study after the frozen transfer test

Generated by `experiments/exp_astro_psf.py` from `psf_raw.npz` and the frozen `m2_raw.npz`; every number below is printed by the script. **POST HOC, NOT A HELD-OUT TEST.** The frozen transfer test (`m2.md`, M53 and M92 with the configuration chosen on M2) was seen first; the kernel family, the adequacy rule (the isotropic fit is kept where its rms residual against the stamp's peak is at most 0.002, which holds for all six M2 stamps) and its goal were fixed afterwards from the stamps alone (no catalogue, no truth), and the same patches are run again. The comparison with the frozen results says how much of the loss a change of kernel recovers on these patches, not how the method would do on new data, and the verdict columns below are descriptive for the same reason.
